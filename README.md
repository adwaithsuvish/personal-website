# 🌐 Personal Portfolio Website

> My personal portfolio site — built to showcase my journey into cyber security, my projects, and what I'm learning along the way.

**Live site:** [adwaithsuvish.github.io/personal-website](https://adwaithsuvish.github.io/personal-website/)

---

## 📖 About

This is a simple, dark-themed personal website built from scratch with HTML and CSS. It includes:

- **Home** — a short intro
- **About** — background on who I am and what I'm working on
- **Projects** — links and descriptions of my cyber security / Python projects

## 📌 Featured Projects Linked on the Site

- **[Port Scanner](https://github.com/adwaithsuvish/port-scanner)** — A multithreaded TCP/UDP port scanner built with Python's `socket` module and `ThreadPoolExecutor`

## 🚀 Running Locally

```bash
git clone https://github.com/adwaithsuvish/personal-website.git
cd personal-website
```

Then open `index.html` in your browser — no build step or server required.
